## Description
This PR implements Feature #3794 - Video Timestamp Bookmarking & Inline Student Notes.

It adds:
- MongoDB `video_notes` collection and CRUD functions in `lib/models/noteModel.js`
- API endpoints `GET /api/notes`, `POST /api/notes`, `PUT /api/notes/[id]`, and `DELETE /api/notes/[id]`
- Zod schema validations for payloads in `lib/validations/notes.js`
- Authentication / RBAC routing security configurations
- Time utility helper `formatTimestamp` mapping seconds to `HH:MM:SS`
- Frontend UI additions:
  - "Add Note" button below the video stream
  - Premium dark-theme Note input/edit modal pre-populating captured video playhead time
  - Interactive personal notes list matching core theme styling with Edit and Delete options
  - Seeking capability on note click
  - Async state handling (loading/error)

Fixes #3794
